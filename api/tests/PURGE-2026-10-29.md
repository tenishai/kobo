# API test purge, wave two (2026-10-29)
Owner ruling 2026-10-29: "we have a lot of redundant tests that don't actually do
any worthwhile tests; of those 100+ files we can most likely reduce it to a
handful." This is the record of what survived, where it went, and why the rest
is gone. TESTING.md says what a contract test is and names the layout.

The branch started from e6cc2d5 and was fast-forwarded onto 7b9a6d0 (0.3.9)
before anything was committed, so the new `test_api_room_services.py` from
#295 was triaged with the rest. The "before" wall time was measured on an
archive of e6cc2d5's `api/` alone (3,771 collected; the two tests that read
`ui/` and `.github/` failed there for want of those directories, nothing
else did); the 3,775 adds the four tests #295 brought.

## Counts

| | before | after |
|---|---|---|
| files under `api/tests/` (test modules) | 118 | 11 |
| test functions | 3,330 | 603 |
| tests collected (with parameters) | 3,775 | 955 (951 pass, 4 skip) |
| wall time, `-n auto`, one laptop | 42 s | 14 s |

Every surviving test's docstring opens with the kind it guards, in the words
of TESTING.md: `Gate (authorization|authentication|ownership|visibility)`,
`Wire shape`, `Data integrity`, `Destruction safety`, `Secrets handling`,
`House rule`, `Production bug`. Bodies were copied unchanged. The only edits
inside a copied test are that first docstring line and, where two files
defined a helper or fixture with one name, the `__<source>` suffix on the
helper's name and its references.

## New tests (the only non-copied code)

Four parametrized tests in `test_gates.py`, written to replace one-test-per-route
copies: `test_every_agent_route_is_404_not_403_for_a_stranger_to_the_group`
(30 routes), `test_every_ready_gated_route_is_409_while_the_agent_is_not_ready`
and `test_every_agent_route_is_404_for_an_unknown_agent` (34 routes), and
`test_every_admin_route_is_403_for_a_signed_in_non_admin` (31 routes). The
existing smoke table gained 17 rows (knowledge delete, retry, directory sync,
persona, restart, secrets, env, grants, invites, requestable, build log) and
the connected guard gained colleague-mode and chat. Two routes were left out of
the tables on purpose: `/repo-access` and `/access/requests` answer "this lane
is off" before any gate in a bare room; their gates are tested with the lane on
in `test_auth.py` and `test_access.py`.
