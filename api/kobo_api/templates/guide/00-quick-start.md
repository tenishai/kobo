# Quick start
<!-- summary: Four steps from nothing to a running agent. -->

1. **Press New agent** in the left rail and choose **Build an agent**.
2. **Pick a persona, type a name, choose your group.** Five built-in personas are ready; **Build your own persona** makes one from a pasted description in a minute.
3. **Press Create agent.** A checklist on the agent's page shows the build. About ten minutes the first time.
4. **Talk to it.** The Chat tab opens when it is ready. Put it in Slack from the Slack tab when you want it there.

No repository to set up, no cluster, no pipeline. The room does that part.

Already have an agent in a repository of your own? Choose **Connect a repository you already have** instead: the room scans it, tells you what it found, and proposes its setup as a pull request your team merges.
