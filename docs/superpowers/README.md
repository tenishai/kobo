# The design record

Everything under this directory is history, kept on purpose. `specs/` holds each arc's design
document and `plans/` the implementation plan that followed it, in chronological order, from
the first assembly-room proof of concept onward. `logo-candidates/` is what it says.

Read them for why the room is shaped the way it is. Do not read them for what the room does
today: a later arc often changed an earlier one, names and paths have moved, and nothing here
is updated after the fact. The current truth is the code, [ARCHITECTURE.md](../../ARCHITECTURE.md)
and its cards under [docs/arch/](../arch/), the in-app guide, and
[docs/what-the-room-does.md](../what-the-room-does.md).
